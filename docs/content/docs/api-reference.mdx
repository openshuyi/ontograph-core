## Module Map

| Module | Import | Key Exports |
|---|---|---|
| Core types | `from "@ontograph/core"` | `EntityType`, `RelationType`, `AttributeDefinition`, `Constraint`, `OntologyDefinition` |
| Builder API | `from "@ontograph/core"` | `defineEntity`, `defineRelation`, `defineAttribute` |
| Expression | `from "@ontograph/core"` | `SafeExpressionEvaluator`, `DerivedAttributeEvaluator` |
| Expr Types | `from "@ontograph/core"` | `Expr`, `LiteralExpr`, `CompareExpr`, `LogicalExpr`, `CallExpr`, `ConditionalExpr`, `ArithmeticExpr`, `ArrayExpr` |
| Query Engine | `from "@ontograph/core"` | `IQueryEngine`, `ObjectSet`, `ObjectSetCompiler`, `Neo4jQueryEngine`, `Neo4jSchemaGenerator` |
| RBAC Security | `from "@ontograph/core"` | `AccessController`, `RoleDefinition`, `PermissionCheckResult` |
| SHACL Validation | `from "@ontograph/core"` | `SHACLShapeGenerator`, `SHACLValidator`, `exprToPropertyShape` |
| Datasource | `from "@ontograph/core"` | `SyncEngine`, `DatasourceDefinition` |
| Exporters | `from "@ontograph/core"` | `OWLExporter`, `SHACLExporter`, `JsonSchemaExporter`, `MermaidExporter`, `ErDiagramExporter`, `DotExporter`, `CytoscapeExporter`, `toCytoscapeElements` — see [Exporters](/docs/core/exporters) |

## Architecture

```
@ontograph/core
│
├── Modeling Layer
│   ├── types.ts              — Core type definitions
│   ├── builder/              — Fluent Builder API
│   └── validator.ts          — Ontology validation
│
├── Execution Layer
│   ├── expression/           — Expr AST + safe evaluator
│   ├── rule-engine.ts        — Rule engine (Expr-first)
│   └── action-engine.ts      — Action engine
│
├── Query Layer
│   ├── query/                — FilterOp → ObjectSet → Cypher
│   └── datasource/           — Datasource mapping + SyncEngine
│
├── Security Layer
│   └── security/             — RBAC AccessController (deny-first)
│
├── Standards Layer
│   ├── validation/           — W3C SHACL generation + validation
│   └── exporters/            — OWL 2 / SHACL / JSON Schema / Mermaid / ER / DOT / Cytoscape export
│
├── Tooling
│   ├── codegen/              — TypeScript type generation
│   ├── versioning.ts         — Version management
│   ├── diff.ts               — Structural diff
│   └── lineage.ts            — Lineage tracking
│
└── Examples
    └── examples/             — Supply chain ontology example
```
